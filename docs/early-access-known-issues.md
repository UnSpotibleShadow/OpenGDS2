# Known limitations — current source / historical RC.4

The game requires the supported, locally imported GameDev2DX.lzh. The title/settings work without it; gameplay needs the import. No original files are bundled.

| Area | Candidate boundary |

Its screen identifies the actual recipient; an unknown slot mapping disables use before spending experience. Older saves with unknown retained eligibility disable speed until an ordinary work pass establishes it. See [M91 evidence](speed-technology-m91.md).
