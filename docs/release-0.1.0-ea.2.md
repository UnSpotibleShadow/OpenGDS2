## Download

Choose **x86_32** for 32-bit Windows or **x86_64** for 64-bit Windows. Extract the
entire ZIP and run **OpenGDS2.exe**. No Godot editor or separate .NET installation
is needed. The matching `.sha256` file verifies each ZIP.

Import your legally obtained **GameDev2DX.lzh** through **Import Original Game**.
The self-extracting EXE is not a supported import input. No original Kairosoft
executable, graphics, sounds or game database are included.

## Existing players

Close the previous game and back up your saves before upgrading. The data folder
remains `%APPDATA%\OpenGDS2`; modern JSON saves and previous-save recovery remain
supported. Refresh the original import if the game requests additional resources.
Original Japanese-game save import remains unsupported.

## Early Access limitations

This remains an experimental reconstruction. Full original campaign/office
progression, exact native timing/RNG and complete presentation parity are not
claimed. Beginner ends after Year 2, December, week 4; Normal is experimental
ongoing play. Negative funds can dissolve the company. Documented original casino
quirks remain. See the bundled **KNOWN_ISSUES.md**, **RELEASE_NOTES.md** and
**BUILD_MANIFEST.json** for scope and package provenance.

Source and packaged automated checks complement the owner's gameplay review;
full display, hardware and multi-year Windows testing remains community work.
Consumer Investigation retains the owner's manual-test waiver.

Report bugs at https://github.com/UnSpotibleShadow/OpenGDS2/issues with version,
architecture, reproduction steps and logs. Never attach original game files.
