# Known limitations

This is an Early Access reconstruction, not a complete port of every original
system or a certification of identical native timing/RNG behavior.

- Beginner ends after Year 2, December, week 4. Normal remains experimental ongoing play.
- Negative cash causes dissolution. Recall liability has no cash-based cap.
- Original-game save import is unsupported. Modern save compatibility can change;
  back up before upgrading and read release notes.
- Complete original campaign/office progression is not established. Separate
  polishing/external-job routes and automatic student skill growth are not
  invented when original behavior is unconfirmed.
- Some older modern saves have unknown source mappings; affected actions can stop
  with an explanation rather than spend money or fabricate history.
- Technologies are employee actions, with documented targeting/replacement quirks.
- Casino games retain recovered original scoring/wager/payout quirks.
- Some bitmap text, geometry and provisional name readings still need comparison.
- English/Japanese interfaces and display aliases do not establish official
  translations or official personal-name pronunciations.
- Validation varies by actual package/architecture. Export-host checks are not
  native Windows testing; check each release's recorded results. Sustained,
  multi-year and display testing remains community work.

Read [current detailed known issues](https://github.com/UnSpotibleShadow/OpenGDS2/blob/main/docs/early-access-known-issues.md)
and the [scope decisions](https://github.com/UnSpotibleShadow/OpenGDS2/blob/main/docs/early-access-decisions.md).
Report crashes, save loss, duplicate charges and blocked progress with reproducible
steps. A missing test result is not itself proof of a gameplay defect.
