# OpenGDS2 0.1.0-ea.1-rc.1 — private test candidate

Prepared for owner testing before a community Early Access release. It is not published, and the private repository is unchanged.

The candidate includes the development/release/sales loop, original-game projects, sequels, manga adaptations, employee management/training, modern save/load, reviews, recalls, calendar/annual events, school facilities, rankings and bank borrowing/repayment. It also includes retained dialogue/meeting window positions, phase-specific looping meeting audio, checkpoint example/fee columns, burst flames, corrected assigned PCs, local English vacancy-sign lettering and occupied school artwork.

The title/window identify the version. The candidate uses the separate OpenGDS2-EarlyAccessTesting data folder so testing does not reuse ordinary development saves or imports. Import the supported original LZH locally and start a new company.

Known limitations are included in KNOWN_ISSUES.md. Follow TEST_CHECKLIST.md and return reproducible reports before release approval. The package includes source/assembly hashes, SHA256SUMS and engine/runtime/community notices. It reuses a Windows debug runtime; native Windows launch has not been tested by the Linux build host. A clean export and the public release gates remain pending.
