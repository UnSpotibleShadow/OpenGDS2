The current source prepares the first community-tested Early Access release.
It has not yet produced or published the final approved Windows ZIP.

The public release-note template is [early-access-public-notes.md](early-access-public-notes.md).
The packager fills its version, reporting URL and data-folder fields for the
actual artifact. Current limitations and test recording are in
[known issues](early-access-known-issues.md) and
[the Windows guide](early-access-testing.md).

media, the corrected English TV patch, translated rival game/publisher names,
award dialogue/reel continuity, sales block charts, original toolbar/settings,
Help text, gameplay backup/virus handling and periodic employee poaching.

Historical private RC.4/M90 packages remain historical. Use the final build
manifest and checksums to identify the source and runtime actually distributed.
