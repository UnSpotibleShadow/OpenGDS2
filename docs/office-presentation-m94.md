# Office presentation and assignment — M94 / #95

This first implementation group follows the bounded handler evidence in
[presentation-handler-audit-m93.md](presentation-handler-audit-m93.md).
Issue #95 stays open for further original-game findings and the other dialogs.

Selecting an employee, then right-clicking a desk, uses the twelve recovered
Single-precision desk diamonds and existing routing/occupancy service. Rest-policy
rejection precedes timer clearing. An occupied desk clears WorkTicks as the native
caller does, but preserves shared contribution units and the current assignment.
The employee walks to an accepted target; the gesture does not teleport them.
Live reports permit office input while blocking checkpoint/transaction dialogs.

Room sprites 87–92 project saved software/hardware progress, development,
debugging, paused and completion labels, and the separate 62×31 table panel behind
the PC. Panel counters are independent per room; completion blinking shares the
native counter across room order. Empty rooms hide all three pieces. Hardware
uses the recovered composite numerator/denominator; software floors progress.
The recovered disruption flag is modeled, without inventing an automatic disaster
event. Global pause freezes office ticks; it does not change the native room label.
Old modern saves receive initial presentation phases; malformed phases are rejected.

English locally derived artwork replaces six verified caption interiors with
community lettering. Native digits, tails, borders, masks, and all other pixels are
retained; Japanese uses the original imported atlas. Cache revisions prevent stale
patched textures. No original pixels, traces, reviewer names or messages are added
to the repository.

Alpha/type and beta/genre options now display added development points beside
fees, preserving saved candidate order, choices and charges. The type window is
505 pixels wide to fit name/points/fee/example columns. The award enum remains
Design internally, but the visible category is Runner-up Grand Prix / 準グランプリ;
selection and prize formulas are unchanged.

Validation: 489 optional-original domain checks; clean application build/import;
English/Japanese gesture, routing and saved-phase checks; a private supported-PE
artwork check restores the fourteen existing bubble interiors and six new caption
interiors then compares every pixel with the original; full core-loop UI checks.
Native Windows motion, timing and window stacking remain runtime comparison limits.
